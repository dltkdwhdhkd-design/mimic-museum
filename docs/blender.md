# 3D 모델 (블렌더)

화면은 Three.js 3D다. 벽·바닥·천장·조명·전시실 표지판은 `js/view3d.js`가 그 라운드 지도에 맞춰 만들고, 받침대·가구·학예사·도장총은 블렌더 파이썬(bpy) 스크립트로 만든 모델을 읽는다. 원본은 스크립트이고 `.glb`와 `.blend`는 거기서 뽑아낸 결과다. 모양을 고치려면 스크립트를 고치고 다시 뽑는다.

| 파일 | 하는 일 |
|---|---|
| `tools/blender/museum.py` | 모델 정의. 모델 하나가 함수 하나 |
| `tools/blender/lib.py` | 기본 도형(상자·원기둥·회전체·공·관 등), 색표 `PALETTE`, 내보내기 |
| `tools/blender/build.py` | 전부 다시 만들어 내보내기 |
| `assets/models/museum.glb` | 게임이 읽는 파일 (250KB쯤) |
| `blend/museum.blend` | 블렌더에서 열어 보는 파일 |

## 다시 뽑기
```
pip install bpy                  # 처음 한 번. 블렌더 앱은 없어도 된다 (bpy 5.x는 Python 3.13)
python3 tools/blender/build.py
```
뽑은 뒤에는 `js/view3d.js`의 `museum.glb?v=` 숫자를 바꾼다. 그래야 학생 기기가 캐시에 남은 옛 모델 대신 새 모델을 받는다.

## 모델
| 이름 | 쓰는 곳 |
|---|---|
| `pedestal` | 전시물 받침대. 윗면 높이 0.87(`js/view3d.js`의 `PED_TOP`과 맞춘다), 앞면 황동 이름판, 윗면 빨간 펠트 |
| `bench` `plant` `trash` `extinguisher` `poster` | 가구이자 미믹이 변신하는 잡동사니. 변신 고르기 카드의 작은 그림도 이 모델을 찍어 만든다 |
| `vending` `rope` `desk` | 가구 |
| `curator` | 학예사. `legL` `legR` `armL` `armR` `head` 부위가 따로 움직인다(걷기·쏘기 자세는 게임이 만든다). 오른손에 도장총 |
| `stampgun` | 학예사 1인칭 도장총 |

## 고칠 때 지킬 것
- 1 = 바닥 한 칸. 원점은 바닥 가운데, Z가 위, 정면은 -Y.
- 재질은 색만 쓴다. 이름이 `team`·`team_d`인 재질은 게임이 팀 색으로 바꾼다(학예사 모자).
- 학예사 부위 이름과 회전 중심(엉덩이·어깨·목)은 그대로 둔다.
- 가구에 눈이나 얼굴을 넣지 않는다. 진짜 가구에도 얼굴이 생겨 숨바꼭질이 깨진다. 움직이는 미믹의 눈알과 '진짜' 도장은 게임이 덧그린다.
- 가구 크기를 크게 바꾸면 `js/view3d.js` 위쪽의 `PICK`(조준 판정 원기둥의 반지름·높이)과 `SHADOW`(바닥 그림자 반지름)도 맞춘다.
- 전시물 606개는 모델로 만들지 않는다. 진짜 물건과 멈춰 있는 미믹이 같은 그림으로 그려져야 구별이 안 되는데, 전시물마다 모델을 만들면 양도 너무 많고 화풍도 섞인다. 전시물은 Twemoji와 코드 그림을 받침대 위에 세운 그림판으로 둔다.

모양을 말로 설명해 주면 스크립트 고치는 것은 Claude가 해도 된다.
